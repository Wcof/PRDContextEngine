# PMSkill — Project Instructions (AtomCode)

## Code Style

- Follow existing patterns in the codebase
- Write tests for new functionality
- Preserve Chinese comments and terminology in existing code
- Keep SKILL.md frontmatter to `name`, `description`, `disable-model-invocation` only

## Project Conventions

- All skills follow the 9-section template: Purpose / Context / Instructions / Thinking Protocol / 关联增强 / 失败模式 / 禁止做什么 / 产出示例 / Further Reading
- Product path: `docs/pm-context/pm-context.md` is the single source of truth
- Risk markers: `[待确认]` / `[假设]` / `[冲突]` are the only allowed uncertainty markers
- Audit triple: `<依据集> → [工具] → [转换: <具体推导类型>] → <产出>`
