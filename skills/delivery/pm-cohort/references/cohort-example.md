# 队列分析完整示例

## 场景

会员产品连续 3 个月新增用户留存下滑，PM 需定位哪批用户异常、为什么。

## PMContext 度量提取

| 度量项 | PMContext 定义 | 来源 |
|--------|---------------|------|
| 留存指标 | D7 留存 / D30 留存 | PMContext 价值验证度量 |
| D30 阈值 | ≥25% | PMContext 价值验证度量 |
| 队列维度候选 | signup 月份 / 首次激活渠道 / 用户类型 | PMContext 用户场景 |
| 功能采纳阈值 | 高级搜索 W4 采纳 ≥40% | PMContext 边界条件 |

## 异常队列识别

### 异常 1：2026-03 D7 留存骤降
- 现象：D7 留存 30%，显著低于平均 37.7%，较 2026-02 下降 15 个百分点
- 假设原因：2026-03/15 上线的新 onboarding（3 步精简）可能引入摩擦——精简掉了"价值展示"步骤
- 验证方式：对 2026-03 流失用户设计 pm-interview 定向访谈（5 人，问 onboarding 体验）；onboarding 改版 A/B 测试（pm-abtest，主指标 D7 留存）

### 异常 2：2026-03 高级搜索采纳断崖
- 现象：W4 采纳 28%，仅为 2026-01（48%）的 58%
- 假设原因：新 onboarding 精简后未引导高级搜索功能，用户不知道此功能存在
- 验证方式：在 onboarding 加回"高级搜索"功能介绍 A/B 测试；对比功能发现页流量

## 跟进研究建议

1. **定性**：2026-03 流失用户 5 人定向访谈（pm-interview，问 onboarding 体验与功能发现路径）
2. **定量**：onboarding 改版 A/B 测试（pm-abtest，主指标 D7 留存，guardrail 高级搜索 W4 采纳）
3. **win/loss**：2026-02（高留存）vs 2026-03（低留存）对比分析，找行为差异

## Python 计算脚本

```python
import pandas as pd
import matplotlib.pyplot as plt

data = {
    'cohort': ['2026-01','2026-02','2026-03'],
    'D7':  [38, 45, 30],
    'D30': [22, 28, 15],
}
df = pd.DataFrame(data).set_index('cohort')
df.plot(marker='o'); plt.ylabel('留存率 %'); plt.title('队列留存曲线')
```
