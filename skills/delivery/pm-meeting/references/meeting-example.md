# 会议纪要完整示例

## 场景

会员续费流程优化评审会，60 分钟，3 人参与。

## 原始转录（片段）

```
张三: 续费流程现在 5 步太长了，用户反馈说要重新填信息很烦
李四: 技术上可以做到 3 步，预填历史信息
王五: 3 步流程我画了下线框，但自动续费默认勾选合规吗？
张三: 法务说默认勾选有风险，取消默认勾选
李四: 那 API 设计我下周一前出
王五: 线框图我这周五前出
张三: 续费提醒渠道还没定，下次再议
```

## 结构化纪要

```markdown
## 会议纪要
**日期**: 2026-07-02 10:00-11:00
**参与者**: 张三(PM)/李四(工程)/王五(设计)
**议题**: 会员续费流程优化

**关键决策**
1. 续费流程从 5 步精简到 3 步（依据: 用户反馈"续费太麻烦"）← PMContext 用户场景"续费流程太麻烦"
2. 取消自动续费默认勾选（依据: 法务合规风险讨论）← PMContext 冲突项"自动续费合规"

**行动项**
| 截止 | Owner | 动作 | PMContext 追溯 |
|------|-------|------|---------------|
| 2026-07-15 | 李四 | 完成一键续费 API 设计 | PMContext 用户场景 |
| 2026-07-10 | 王五 | 出 3 步流程线框图 | PMContext 用户场景 |

**未决问题**
- 续费提醒触达渠道（短信/邮件/站内）未定 → 下次会议议
```
