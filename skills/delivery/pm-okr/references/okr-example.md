# OKR 完整示例

## 场景

会员产品 Q3 OKR 拆解，PMContext 已有"月付会员数/D30 留存/续费率"度量定义。

## 三套候选

### 套 A（增长导向）
```
Objective: Q3 让会员体系成为高频创作者的首选
Key Results:
- KR1: 月付会员数从 5K 到 8K（信心度 70%）← PMContext 价值验证度量"月付会员数"
- KR2: D30 留存从 22% 到 28%（信心度 65%）← PMContext 价值验证度量"D30留存"
- KR3: 续费率从 68% 到 75%（信心度 60%）← PMContext 价值验证度量"续费率"
```

### 套 B（留存导向）
```
Objective: Q3 让现有会员离不开这个产品
Key Results:
- KR1: D30 留存从 22% 到 30%（信心度 60%）
- KR2: 周活跃天数从 3.2 到 4.5（信心度 65%）
- KR3: NPS 从 32 到 45（信心度 70%）
```

### 套 C（体验导向）
```
Objective: Q3 让会员感受到每一次使用都被重视
Key Results:
- KR1: CSAT 从 78% 到 88%（信心度 70%）
- KR2: 客服首次响应从 4h 到 1h（信心度 65%）
- KR3: onboarding 完成率从 60% 到 80%（信心度 60%）
```

## 对比表

| 维度 | 套 A（增长） | 套 B（留存） | 套 C（体验） |
|------|------------|------------|------------|
| 战略对齐 | ✅ 对齐公司增长战略 | 🟡 偏留存 | 🟡 偏体验 |
| 信心度均值 | 65% | 65% | 65% |
| 可测性 | ✅ 全可测 | ✅ | 🟡 CSAT 主观 |
| 与 pm-metrics NSM 一致性 | ✅ KR2 是 NSM input | ✅ | 🟡 弱关联 |

## KR/KPI/NSM 关系矩阵

| 概念 | 定义 | 本 OKR 关系 |
|------|------|------------|
| KR | 季度定量进展度量 | 套 A 的 3 个 KR |
| KPI | 长期跟踪关键指标 | KR1/KR3 是 KPI |
| NSM | 单一客户中心 KPI | KR2 是 pm-metrics NSM"会员活跃度"的 input metric"D30留存" |

## 选定：套 A

放弃套 B（与公司增长战略不一致）、套 C（CSAT 主观性高，可测性弱）。

## 审计三元组

`<依据集: [PMContext 价值验证度量"月付会员数"+阈值, PMContext 用户场景"高频创作者"]> → [工具: /pm-okr, 规则: Wodtke OKR 框架] → [转换: 从度量定义推导可测 KR，同义词推导：PM 说"增长"→映射 KR1 月付会员数] → <产出: 套 A OKR + 3 KR + 信心度>`
