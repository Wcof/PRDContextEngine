# Roadmap 转换完整示例

## 场景

会员产品 Q2 roadmap 原本是功能清单，需转为 outcome 导向。

## 原始 roadmap（output）

- Q2: 高级搜索筛选、AI 推荐、仪表盘改版

## 转换表

| 原 initiative | outcome 陈述 | 关键度量 | 依赖/排序 | PMContext 追溯 |
|--------------|-------------|---------|----------|---------------|
| 高级搜索筛选 | Enable 高频创作者 to 50% 更快找到素材 so that 搜索退出率降 30% | 搜索退出率、首次搜索耗时 | 无 | 用户场景"找素材慢" |
| AI 推荐 | Enable 创作者 to 发现相关素材 so that 人均素材数 +20% | 人均素材数 | 推荐模型就绪 | 价值验证度量"人均素材数" |
| 仪表盘改版 | Enable 运营 to 80% 更快监控全系统 so that 仪表盘加载降 80% | 加载耗时 | 无 | 边界条件"加载慢" |

## 替代方案考量

| initiative | 替代方案 | 评估 |
|-----------|---------|------|
| 高级搜索筛选 | 智能分类标签（更低实现成本） | 建议先做标签，3 个月后评估是否仍需筛选 |
| AI 推荐 | 协同过滤 vs 内容推荐 | 协同过滤冷启动差，先做内容推荐 |
| 仪表盘改版 | 性能优化 vs 重新设计 | 先性能优化（加载慢根因），设计微调 |

## 战略对齐

```
公司战略: 提升创作者生产力
outcomes 对齐:
- "更快找到素材" → 生产力核心
- "发现相关素材" → 生产力扩展
- "更快监控" → 运营效率（支撑）

关键假设: 创作者找素材慢是核心痛点（PMContext 用户场景已验证）
```

## 与 pm-okr 交叉验证

| outcome | 对应 OKR KR |
|---------|------------|
| 更快找到素材 | 无直接对应（建议 Q3 OKR 加入） |
| 人均素材数 +20% | 套 A KR2 的 input |
| 仪表盘加载 | 无（运营支持，非客户 OKR） |

## 审计三元组

`<依据集: [原始 roadmap 3 initiatives, PMContext 用户场景"找素材慢"+价值验证度量]> → [工具: /pm-roadmap, 规则: outcome 三段式转换] → [转换: 从功能推导客户成果与业务影响，同义词推导：PM 说"搜索筛选"→映射"更快找到素材"] → <产出: 3 outcome + 度量 + 替代方案>`
