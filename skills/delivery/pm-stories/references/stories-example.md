# 用户故事完整示例 + 3C/INVEST 对照

会员续费用户故事完整示例。

## 3C 框架对照

| 3C | 内容 | 说明 |
|---|---|---|
| Card | 一键续费 | 简短标识，backlog 卡片 |
| Conversation | 续费流程 5 步流失率高，预填历史信息减少摩擦 | 与团队讨论的上下文 |
| Confirmation | 续费完成率 ≥65%，3 秒内完成，无需重填 | 可观测验收 |

## INVEST 准则自检

| 准则 | 是否满足 | 说明 |
|---|---|---|
| Independent | ✓ | 不依赖其他故事，可单独交付 |
| Negotiable | ✓ | 实现方式可协商（预填方式可讨论） |
| Valuable | ✓ | 续费完成率提升直接降流失 |
| Estimable | ✓ | 改造续费页+支付调用，可估 |
| Small | ✓ | 单续费页改造，1 sprint 可完成 |
| Testable | ✓ | 完成率/耗时/字段数均可测 |

## 完整用户故事

```markdown
# 用户故事: 会员续费

## Story-1: 一键续费
- **Card**: 一键续费
- **Conversation**: 续费流程 5 步流失率高（PMContext 摩擦力"续费太麻烦"）。预填历史支付信息，一键完成续费。
- **Confirmation**:
  - [ ] 续费完成率 ≥ 65% ← PMContext 价值验证度量
  - [ ] 3 秒内完成支付
  - [ ] 无需重新填写任何字段
  - [ ] 支付失败有明确错误提示并回滚权益
- **INVEST**: 独立✓ 可协商✓ 有价值✓ 可估✓ 小✓ 可测✓
- **追溯**: PMContext 摩擦力"续费太麻烦" + 价值验证度量"续费率60%→75%"

## Story-2: 到期多渠道提醒
- **Card**: 到期多渠道提醒
- **Conversation**: 用户常忽略单一推送提醒（PMContext 用户场景"忘记到期日"）。多渠道（App+短信+邮件）分级提醒。
- **Confirmation**:
  - [ ] 到期前 7/3/1 天分别提醒
  - [ ] 三渠道触达率合计 ≥ 90%
  - [ ] 提醒含一键续费入口
- **INVEST**: 独立✓ 可协商✓ 有价值✓ 可估✓ 小✓ 可测✓
- **追溯**: PMContext 摩擦力"忘记到期日"

## Story-3: 权益价值可视化
- **Card**: 权益价值可视化
- **Conversation**: 续费时用户不确定权益值不值（PMContext [假设]）。展示已用权益价值统计。
- **Confirmation**:
  - [ ] 续费页展示"已为你节省 ¥X / 已用权益 N 项"
  - [ ] 权益使用率提升 ≥15%
- **INVEST**: 独立✓ 可协商✓ 有价值✓ 可估✓ 小✓ 可测✓
- **追溯**: PMContext [假设: 权益价值不清, 6/10]
```
