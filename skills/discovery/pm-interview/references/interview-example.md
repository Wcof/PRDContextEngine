# 访谈脚本完整示例 + Mom Test 问题改写对照

## 完整访谈脚本示例（会员续费）

```markdown
# 访谈脚本

> 来源: PMContext 会员续费
> 访谈目标: 3 个 | 目标受访者: 高频创作者 | 预计时长: 30-40 分钟

## 访谈目标
1. 续费时的真实摩擦点是什么
2. 现在用什么平替管理续费
3. 什么会让他们愿意续费

## 目标受访者
- 高频创作者（每周创作 ≥3 次）
- 现有付费会员（≥1 个续费周期）

## 脚本

### 暖场（2-3 分钟）
- 介绍访谈目的（研究续费体验，不推销）
- 确认录音许可
- 简单破冰（最近在创作什么）

### 核心探索：JTBD（15-20 分钟）
- 上次续费会员时发生了什么？（过去时）
- 当时最烦的是哪一步？（找摩擦）
- 你现在怎么记得要续费？（现状平替）
- 续费顺利时，你之后做了什么？（成功是什么样）
- 你愿意为"不再操心续费"投入多少？（WTP）

### 收尾（3-5 分钟）
- 还有什么我没问但你觉得重要的？
- 能否后续再聊 15 分钟？

## 探查技巧
- 问"上次"非"你会"（过去时 > 未来时）
- 问"做了什么"非"你觉得"（行为 > 意见）
- 不 pitch 解决方案（验证假设≠推销）
- 强情绪信号是真实痛点/愉悦，深挖

## The Mom Test 规则
- 问过去不问未来
- 问生活不问想法
- 不 pitch
- 多听少说
```

## Mom Test 问题改写对照表

| ❌ 反例（违反 Mom Test） | ✅ 正例（符合 Mom Test） | 为什么 |
|---|---|---|
| 你会续费会员吗？ | 上次你续费时发生了什么？ | 未来意愿不可靠，过去行为才真实 |
| 你觉得一键续费这个想法怎么样？ | 你现在怎么完成续费的？ | 不 pitch 想法，问现状行为 |
| 你想要更快的续费流程吗？ | 续费时哪一步最让你烦？ | 不引导答案，找真实摩擦 |
| 你愿意为会员付多少钱？ | 你上次付了多少？为什么？ | 问已发生的事实，非假设意愿 |
| 你认为会员权益值吗？ | 你上次用会员权益是什么时候？ | 行为比意见真实 |
| 如果有 X 功能你会用吗？ | 你现在怎么解决没有 X 的问题？ | 不问假设，问现状平替 |
