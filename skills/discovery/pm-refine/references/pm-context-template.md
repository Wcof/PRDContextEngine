# PMContext 产物模板

`docs/pm-context/pm-context.md` 单文件自包含，按业务领域组织 heading。

## 模板

```markdown
# PMContext: <需求名>
## 概述
### 问题与目标
### 现状平替与摩擦力
### 价值验证度量
## <页面/功能名>（如：用户登录）
### 事实
- <事实项> ← 来源: <材料/推断/对话: PM 确认>, 审计: <[依据集] → [/pm-refine 8维之"维度"] → [具体推导逻辑] → 事实>
### 规则
- <规则项> ← 来源: <材料/推断/对话: PM 确认>, 审计: <[依据集] → [/pm-refine 8维之"维度"] → [具体推导逻辑] → 规则>
### 验收
- <验收项> ← 来源: <材料/推断/对话: PM 确认>, 审计: <[依据集] → [/pm-refine 8维之"维度"] → [具体推导逻辑] → 验收>
## <页面/功能名>（如：支付流程）
### 事实
- <事实项> ← 来源: <材料/推断>, 审计: <[依据集] → [/pm-refine 8维之"维度"] → [具体推导逻辑] → 事实>
### 规则
- <规则项> ← 来源: <材料/推断>, 审计: <[依据集] → [/pm-refine 8维之"维度"] → [具体推导逻辑] → 规则>
### 验收
- <验收项> ← 来源: <材料/推断>, 审计: <[依据集] → [/pm-refine 8维之"维度"] → [具体推导逻辑] → 验收>
## 全局约束
## 决策日志
| 决策点 | 选项A | 选项B | 最终选择 | 理由 | 来源 | 依据源数 | 工具名摘要 |
|--------|------|------|---------|------|------|---------|-----------|
## 假设清单与验证计划
| 假设 | 置信度(1-10) | 风险类型 | 验证方式 | 成功指标/阈值 | 验证时机 |
|------|------------|---------|---------|--------------|---------|
## 风险项 [待确认] [假设] [冲突]
## 信息缺口
- <维度>：<缺什么，需 PM 补充什么>
```

## 标记规则

每项必须标注来源与审计三元组：

- **来源**：`材料` / `推断` / `对话: PM 确认` 之一
- **审计三元组**：`[依据集] → [/pm-refine 8维之"维度"] → [具体推导逻辑] → 产物类型(事实/规则/验收)`
  - 依据集：该推断依据的材料项集合
  - 维度：8 维精炼中对应维度
  - 具体推导逻辑：从依据到产物的推理链（禁同义反复）
  - 产物类型：事实/规则/验收

## 增量更新

- 新材料 → 追加到对应 heading，标来源与审计
- 冲突 → 标 `[冲突]` 列入风险项，不静默覆盖
- 待确认 → 标 `[待确认]` 列入信息缺口
- 假设 → 标 `[假设]` + 置信度，列入假设清单与验证计划
